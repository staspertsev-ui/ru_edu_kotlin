# Контроль уровня Международного Нормализованного Отношения

Международное Нормализованное Отношение (далее МНО) — это стандартизированный показатель, используемый для оценки
свертываемости крови.
Если МНО повышено, это указывает на повышенный риск кровотечений, а если понижено — на повышенный риск
тромбообразования.

Основная задача проекта - это ведение статистики соотношения дозы принимаемых антикоагулянтов и МНО для больных и их
врачей.
Данная статистика необходима для понимания влияния дозы антикоагулянтов на МНО. И позволит пациенту 
скорректировать дозу самостоятельно или врачу дать рекомендации по её изменению.
