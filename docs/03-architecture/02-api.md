#### 2. Бизнес-функции (методы)

**Методы получения справочников**

1. **`antiс.read`** - получение справочника видов антикоагулянтов
2. **`dose.read`** - получение справочника единиц измерения дозировки
3. **`spec.read`** - получение справочника специализаций врачей

**CRUDS для результатов измерений**

1. **`res.create`** - Добавление нового результата измерений
    - *Бизнес-правило*: Только больные могут создавать результаты измерений
2. **`res.update`** - изменение результата измерений
    - *Бизнес-правило*: Только создатель может вносить изменение в измерение
3. **`res.read`** - получение результата измерения
4. **`res.delete`** - удаление результата измерения
    - *Бизнес-правило*: Только создатель может удалять измерение
5. **`res.period`** - получение результатов измерений за период
    - *Бизнес-логика*: Возвращает доступные измерения с пагинацией
    - *Фильтры*: За период
    -

**CRUDS для результатов рекомендаций**

1. **`reс.create`** - добавление нового результата измерений
    - *Бизнес-правило*: Только доктора могут создавать рекомендации и только на пациентов у которых указаны.
2. **`reс.update`** - обновление рекомендации
    - *Бизнес-правило*: Только создатель может вносить изменение в рекомендацию
3. **`reс.read`** - получение рекомендации
4. **`reс.delete`** - удаление рекомендации
    - *Бизнес-правило*: Только создатель может удалять рекомендацию
5. **`reс.period`** - получение рекомендаций за период
    - *Бизнес-логика*: Возвращает доступные измерения с пагинацией
    - *Фильтры*: За период, врач
    -

#### 3. Бизнес-правила

1. **Видимость рекомендаций**:
    - `public`: Видно всем пользователям
    - `private`: Только доктору
    - `patient`: Видно доктору и пациенту
    -
2. **Видимость измерений**:
    - `public`: Видно всем пользователям
    - `private`: Только пациенту
    - `patient`: Видно доктору и пациенту

3. Ограничения для пациентов:
    - Могут видеть рекомендации только от указанных при регистрации врачей
    - Могут добавлять 1 результат измерения в день

4. Ограничения для докторов:
    - Могут создавать рекомендации только для пациентов, у которых указаны при регистрации
    - Могут видеть измерения только для пациентов, у которых указаны при регистрации
    - Могут добавлять 1 рекомендацию для 1 пациента в день

#### 4. Бизнес-метрики успеха

1. **Скорость получения статистики**: 95% запросов должны возвращать результаты < 10 сек
2. **Скорость получения рекомендаций докторов**: 95% запросов должны возвращать результаты < 5 сек
3. **Ограничения**:
    - Новые пользователи (Врачи): 10 запросов/минуту
    - Новые пользователи (Больные): 2 запроса/минуту
