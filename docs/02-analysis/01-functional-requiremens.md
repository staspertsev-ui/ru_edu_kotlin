### 1. Регистрация и управление учетной записью:

1.1. **Регистрация на платформе:**

- **Источник требования:** Лечебные заведения, врачи, пациенты.
- **Описание требования:** Реализовать функционал регистрации с обязательными полями для заполнения и
  подтверждением через электронную почту.
- Поля для заполнения включают:
    - Электронная почта (обязательное поле)
    - Пароль (обязательное поле)
    - Тип пользователя (Врач/Пациент)
- Поля для Пациентов
    - Врачи, которым будет доступна статистика МНО
    - Возраст
    - Диагноз
    - Контактный телефон
    - Антикоагулянт (обязательное поле)
- Поля для Врачей
    - Компания
    - Контактный телефон
- **Приоритет требования:** Высокий.

1.2. **Вход в систему:**

- **Источник требования:** Все типы пользователей.
- **Описание требования:** Обеспечить возможность аутентификации пользователей по электронной почте и паролю.
- **Приоритет требования:** Высокий.

### 2. Управление профилем пользователя:

2.1. **Профиль пользователя:**

- **Источник требования:** Все типы пользователей.
- **Описание требования:** Разработать возможность заполнения и редактирования профиля пользователя
- **Приоритет требования:** Средний.

- **Источник требования:** Пациент
- **Описание требования:** Разработать возможность изменения списка врачей, которым будет доступна статистика пациента
- **Приоритет требования:** Средний.

### 3. Управление справочниками антикоагулянтов



- **Источник требования:** Пациент
- **Описание требования:** Разработать возможность сохранения следующих данных:
    - Пациент (id)
    - Дата измерения
    - Уровень МНО
    - Доза антикоагулянта
    - Вид антикоагулянта
- **Приоритет требования:** Высокий.




### 4. Управление статистикой:

4.1. **Добавление измерений:**

- **Источник требования:** Пациент
- **Описание требования:** Разработать возможность сохранения следующих данных:
    - Пациент (id)
    - Дата измерения
    - Уровень МНО
    - Доза антикоагулянта
    - Вид антикоагулянта
- **Приоритет требования:** Высокий.

4.2. **Просмотр статистики измерений:**

- **Источник требования:** Пациент
- **Описание требования:** Разработать возможность получения измерений за период по текущему пользователю (пациенту)
- **Приоритет требования:** Высокий.

4.2. **Просмотр статистики измерений:**

- **Источник требования:** Врач
- **Описание требования:** Разработать возможность получения измерений за период по указанному пациенту
- **Приоритет требования:** Высокий.
