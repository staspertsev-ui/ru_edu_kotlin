# Целевая аудитория

Больные, которые принимают антикоагулянты прямого действия. 
Врачи, которые ведут таких пациентов.
Часть антикоагулянтов (например: Варфарин) требует постоянный контроль МНО.

## Гипотетический портрет Больной

  1. Больной с протезом клапана сердца
     1. Возраст с 18 лет. 
     2. Способны сами осуществлять измерение уровня МНО и подбирать правильную дозу антикоагулянтов на основе измерений.
     3. Принимает антикоагулянты, которые требуют контроль МНО
  2. Родители детей с протезами клапана сердца.
     1. Ребенок принимает антикоагулянты, которые требуют контроль МНО
  3. Больной с тромбофлебитом
     1. Принимает антикоагулянты, которые требуют контроль МНО
  4. Больной, которому требуется лечение и профилактика осложнений фибрилляции предсердий
     1. Принимает антикоагулянты, которые требуют контроль МНО
  5. Больной после операций на сердце
     1. Принимает антикоагулянты, которые требуют контроль МНО
